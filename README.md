# ERPNext Fitter Snacker Implementation

## Project Overview
This project focuses on evaluating and implementing an Enterprise Resource Planning (ERP) solution for a fictional manufacturing company, Fitter Snacker. The company was facing operational issues caused by disconnected systems for accounting, sales, inventory, supply chain, and human resources.

The project compares ERPNext and Odoo, analyzes business requirements, and recommends ERPNext as the most suitable solution due to its open-source model, manufacturing support, inventory management features, and cost-effectiveness.

## Business Problem
Fitter Snacker was using QuickBooks for accounting along with separate systems for sales, inventory management, and HR. This created:

- Duplicate data entry
- Inconsistent information across departments
- Order processing errors
- Late deliveries
- Excess inventory
- Limited real-time reporting

## ERP Solutions Evaluated
The project evaluated two open-source ERP platforms:

- Odoo
- ERPNext

The comparison was based on:

- Cost
- Usability
- Interoperability
- Documentation
- Supportability
- Configurability
- Manufacturing support
- Long-term viability

## Recommended Solution
ERPNext was selected as the recommended ERP platform because it provides strong support for manufacturing, inventory management, accounting, sales, and supply chain workflows while remaining fully open-source and cost-effective.
